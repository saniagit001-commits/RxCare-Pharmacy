# 💊 RxCare - Online Pharmacy Website

## Overview

**RxCare** is a modern and user-friendly pharmacy website developed using **HTML, CSS, and JavaScript**. The platform is designed to provide customers with a convenient online experience for browsing medicines, healthcare products, and pharmacy services.

The project focuses on creating a responsive and visually appealing web interface that simulates the functionality of a real-world online pharmacy. RxCare aims to improve accessibility to healthcare products while maintaining a clean and intuitive user experience.

---

## 🚀 Features

- Responsive and mobile-friendly design
- Modern and attractive user interface
- Product browsing and categorization
- Search functionality for medicines and healthcare products
- Featured products section
- Customer testimonials and reviews
- Contact and support section
- Interactive navigation menu
- Smooth animations and transitions using JavaScript
- Fast and lightweight webpage performance
